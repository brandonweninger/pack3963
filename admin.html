Leadership Photo Admin

Authorized Pack 3963 leaders can manage the public photo gallery here.

Open the photo manager

Sign in to Pages CMS, select brandonweninger/pack3963, and open Photo Gallery.

Sign in to Photo Admin

Publishing checklist

  1. Upload a JPG, JPEG, PNG, or WebP image.
  2. Add a clear image description for accessibility.
  3. Add an optional caption and event date.
  4. Do not include a child's full name.
  5. Confirm that the Pack has permission to publish the photo.
  6. Save the gallery and allow GitHub Pages a few minutes to rebuild.

This page links to the protected editing service, but the photos published through it are public on the Pack website.
